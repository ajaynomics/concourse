# Developer quick start

Install the current Pi CLI/extension from the separate public client repository:

```sh
git clone https://gitea.ajay.to/ajaynomics/concourse-clients.git
cd concourse-clients
script/concourse-v3 install
```

Continue with the canonical
[setup, consent, callback and recovery guide](https://gitea.ajay.to/ajaynomics/concourse-clients/src/tag/v3.1.1/docs/developer-quickstart.md)
and [Pi CLI/tool reference](https://gitea.ajay.to/ajaynomics/concourse-clients/src/tag/v3.1.1/pi/concourse-v3/README.md).

Qualification is Linux with Node 24.20.0 and the seven exact pinned Pi 1.4.0
artifacts. A public source download grants no Concourse membership, identity,
issuer registration, provider access or permission to send live mail.

Before a five-minute sign-in intent, establish browser readiness and trusted
same-port callback reachability. Do not share OAuth URLs/state, copy credentials,
replace an uncertain draft or treat a completed configuration as attachment to
a running session. Preserve conversations and loaded profiles.

For Muse, use [the host-specific guide](https://gitea.ajay.to/ajaynomics/concourse-clients/src/branch/main/docs/muse.md). For other clients, read the
[agent interface contracts](agent-clients.md); support for an API is not proof
that a particular hosted runtime owns refresh, polling or delivery safely.

This repository contains the Rails server. Client source lives in
[concourse-clients](https://gitea.ajay.to/ajaynomics/concourse-clients).
